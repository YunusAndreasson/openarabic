## 🛠️ Tools & Commands Reference

### Search Patterns

```bash
# Find unused exports (requires knip or similar)
yarn check-unused

# Find all usages of a specific export
grep -r "exportName" --include="*.tsx" --include="*.ts"

# Find components never imported
rg "export.*function Component" -t ts -t tsx

# Find constants never used
rg "export const CONSTANT" constants/ -t ts

# Find TODO/FIXME comments
rg "TODO|FIXME|HACK|TEMP" -t ts -t tsx

# Find commented code
rg "^[ \t]*//" -t tsx -t ts | head -100

# Count usages of a symbol
rg "SYMBOL_NAME" --count --sort path
```

### Bundle Analysis

```bash
# Build for production
yarn build

# Analyze bundle (if available)
npx react-native-bundle-visualizer

# Check Metro bundle size
npx react-native bundle --platform ios --dev false --entry-file index.js --bundle-output /tmp/bundle.js
ls -lh /tmp/bundle.js
```

### TypeScript Analysis

```bash
# Find unused locals and parameters
npx tsc --noUnusedLocals --noUnusedParameters --noEmit

# Generate project references
npx tsc --showConfig
```

## 📝 Cleanup Methodology

### For Each Cleanup Task:

1. **Identify**: Use tools/commands to find candidates
2. **Verify**: Double-check usage with grep/search
3. **Document**: Note what you're removing and why
4. **Remove**: Delete code/file
5. **Test**: Run tests to ensure nothing breaks
6. **Validate**: Run `yarn validate`
7. **Commit**: Small, focused commits

### Commit Message Format:

```
chore: remove unused [type] from [location]

- Remove [specific item 1]
- Remove [specific item 2]
- Reason: [why it's safe to remove]

Bundle size: [before] → [after] (-X kb)
```

## 🚨 Safety Rules

### ⚠️ DO NOT REMOVE:

- Anything in `types/database.types.ts` (auto-generated)
- Expo configuration files
- Build/deployment scripts
- Environment variable references
- Error tracking setup

### ✅ SAFE TO REMOVE:

- Unused components with 0 imports
- Constants never referenced
- Utility functions never called
- Types with no usages
- Commented-out code

### 🤔 VERIFY CAREFULLY:

- Dependencies used in production
- Code used by external systems (API callbacks)
- Feature flags (may be toggled externally)
- Analytics events (may be used for tracking only)
