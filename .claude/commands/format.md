# Format

Auto-format all files using Prettier.

## Usage

```
/format
```

## Command

```bash
yarn prettier:fix
```

## Behavior

1. Run prettier with the fix flag
2. All files will be automatically formatted
3. Report success when complete

## Notes

- **ALWAYS** use this command when prettier check fails
- **NEVER** manually fix formatting issues
- Prettier handles all formatting automatically
- This prevents wasting time on formatting rules
